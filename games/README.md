# games/ — the gaming lane

Gaming is a real lane in this project, not a side hobby: two of these files are
**worldbuilding that feeds the fiction** (the heist game and several game ideas are
set in the **Five Families / Project Family universe** — the same canon as the
fantasy trilogy and the Longshoreman serial). One canon, shared between the games
and the books; the trilogy's ledgers remain the source of truth.

## What's here

**Creative / canon (feeds the writing):**
- `heist-game-design.md` — design ledger for the text-first mobile heist game
  (Five Families world; NYC / Hall of Heirs). Cross-linked to
  `docs/five-families-world-bible.md`.
- `game-ideas.md` — capture-only vault for game concepts (the heist game + a
  Hitman-style assassination game, both in the Five Families world). Not active
  development — books come first.

**Taste / reference (recommendations):**
- `gaming-preferences.md` — Alec's gaming tastes, standing rec queue, and the
  filters that predict his reactions (turn-based, legible-hard > opaque-hard,
  draft-not-collection, bails on system-cliffs, etc.). Doubles as target-player
  reference for his own game designs.
- `steam-library_2026-08-16.md` — a library snapshot (games with hours +
  last-played), read locally from his PC. Dated; a fresh snapshot supersedes it.

## Note
Moved here from `docs/` on 2026-08-28 (was four loose files). The `_2026-08-16`
date on the library file is a snapshot stamp — Steam is unreadable from the remote
environment, so the library is only as current as the last local read.
