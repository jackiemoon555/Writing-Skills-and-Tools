# Architecture Plan: Claude Orchestrator & Gemini Execution Agent

## 1. Overview
This architecture uses **Claude Max** as the primary strategy and logic engine ("The Architect") while delegating heavy data retrieval, real-time web search, and massive context digestion to **Gemini Pro** ("The Executor"). A lightweight verification tool acts as the bridge between the two platforms.

---

## 2. System Workflow Diagram

```
+-------------------------------------------------------------+
|                     CLAUDE MAX (Architect)                  |
| - Builds Master Research Directive                          |
| - Reviews final condensed qualitative summaries              |
| - Executes final bet sizing & macro strategy decision        |
+------------------------------+------------------------------+
                               |
                               v
+-------------------------------------------------------------+
|                      GEMINI PRO (Executor)                  |
| - Scrapes real-time sports news & beat writer updates        |
| - Processes multi-MB feeds, PDFs, press conference transcripts|
| - Generates structured qualitative output                   |
+------------------------------+------------------------------+
                               |
                               v
+-------------------------------------------------------------+
|                     VERIFICATION TOOL                       |
| - Verifies source citations and ground truth facts          |
| - Flags discrepancies, outliers, or outdated sources        |
| - Trims output down to a ~300-word clean summary            |
+------------------------------+------------------------------+
                               |
                               v
+-------------------------------------------------------------+
|                     CLAUDE MAX (Final Review)               |
| - Receives verified, zero-bloat summary                     |
| - Keeps context window clean and token usage minimal        |
+-------------------------------------------------------------+
```

---

## 3. Implementation Options

### Option A: Manual Bridge (Fastest to set up)
1. **Prompt Claude:** Ask Claude to construct a structured prompt template for a specific slate/game.
2. **Execute on Gemini:** Paste the template into Gemini Pro along with raw links, articles, or search queries.
3. **Verify & Pass Back:** Run Gemini's output through your verification tool, then paste the ~300-word result back into Claude.

### Option B: Model Context Protocol (MCP) Bridge
If using the **Claude Desktop App**, set up a local MCP server that calls the Gemini API under the hood.

1. **Configuration:** Add an MCP server definition to `claude_desktop_config.json`:
   ```json
   {
     "mcpServers": {
       "gemini-executor": {
         "command": "python",
         "args": ["/path/to/gemini_mcp_bridge.py"],
         "env": {
           "GEMINI_API_KEY": "YOUR_GEMINI_API_KEY"
         }
       }
     }
   }
   ```
2. **Execution:** Inside Claude Desktop, issue commands directly:
   > *"Claude, execute the deep qualitative research directive for tonight's game using the Gemini tool and return the verified summary."*

### Option C: Python Automated Script
For end-to-end automation, run a script that handles the pipeline programmatically:

```python
import google.generativeai as genai

genai.configure(api_key="YOUR_GEMINI_API_KEY")

def run_gemini_research(directive_prompt, game_data):
    model = genai.GenerativeModel('gemini-3.1-pro')
    full_prompt = f"{directive_prompt}\n\nDATA/INPUTS:\n{game_data}"
    
    response = model.generate_content(full_prompt)
    return response.text

# 1. Take directive generated by Claude
# 2. Pass to Gemini for heavy research
# 3. Output to Verification Tool
```

## 4. Key Benefits
* **Zero Token Limits on Claude:** Eliminates context bloat caused by pasting thousands of words of raw articles into Claude threads.
* **Real-time Web Grounding:** Leverages Google's native search integration for last-minute sports news.
* **Verification Protection:** Ensures AI-generated research is cross-checked against source material before making strategy decisions.
