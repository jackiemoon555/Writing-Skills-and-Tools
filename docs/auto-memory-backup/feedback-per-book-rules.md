I really need it to carry so you don't assume in the future"):**

meant to govern. Claude did this on 2026-08-29 (applied an old fantasy-ledger register note to
a new character design) and was corrected the same day.

**How to apply:** before critiquing or capturing canon on any project, check WORKING_RULES
rule 4b + that project's own ledger/bible for ITS declared rules. If it has none, it has none
— proceed label-free.
