television and anime influences that feed the fiction. Capture-only — observed
and recorded, never prescribed.

## Seeded from the existing record (already-named show influences)
- **Naruto — the Akatsuki** + **Hunter x Hunter — the Phantom Troupe**: the two
  named inspiration models for the Five Families shadow organization (small
  roster, individually legendary, institution-proof, hunting the powered; Spider
  doctrine / hidden true master). Reference DNA captured in
  `docs/five-families-world-bible.md` — membership/name/emblem all UNDECIDED.
- **Cowboy Bebop** — the ending register for the No More Heroes idea (elegiac,
  costly ascent; the author's fork: the MC has something to live for, unlike
  Spike). See `docs/future-ideas.md`.
- **The Wire (Season 2)** — the docks/labor lineage of the Longshoreman serial
  (the dad as the port's Frank Sobotka). See `docs/future-ideas.md`.
- **K-drama chaebol dynamics** — the old-money dynastic engine behind the Five
  Families world (succession, marriage politics, poor-kid-among-heirs); named by
  the author 2026-08-29 as the core inspiration lineage, applied to America with
  the families as the government.
