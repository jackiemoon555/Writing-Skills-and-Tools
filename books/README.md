# books/ — the prose influence lane

Parallel to `games/` (author's request, 2026-08-30): a dedicated home for book
influences that feed the fiction. Capture-only — observed and recorded, never
prescribed.

**Relationship to `tracker/reading-log.md`:** the reading log tracks what the
author has actually read/finished (with the influence map). This lane is for the
*influence entries themselves* — which book fed which project, and through what
mechanism. The reading log stays the record of reading; this folder holds the
lineage.
